## Version 25 admission

The old select output carries an object containing selected rows. Version 25
instead exposes the selected model and its selectedChange array output. Both
application templates need that explicit event migration while retaining the
existing parent handler shape. Relying only on compilation could miss this
break: Angular accepts an unrecognized event binding that never emits the
expected library selection. Real click consumers are therefore required before
and after the migration. Query parameters, paging size, raw data, disabled-ID
policy and existing loading/error feedback remain part of the consumer contract.

The corrected old-library control passes all 31 cases with a normal exit. A
frozen install changes only ngx-datatable; all other installed package versions
and lock blocks remain exact, and all 28 published files match the verified
archive. The unadapted v25 runtime then fails 18 strict HTTP/interaction cases:
initial rendering sends two matching page-zero requests before selection can be
exercised. The first request is replaced through the existing cancellation path.
The other 13 cases pass. No HTTP matcher is relaxed to ignore the extra request.

A separate onPage handler ignores repeated library events at the current offset.
Initial loading and the explicit Retry control still call changePage directly,
so same-page retries and request cancellation remain available. Both templates
use the adapter. A subsequent control retains the legacy selection event binding
to distinguish paging compatibility from selection compatibility.

With only the page adapter, all 27 existing cases pass again. Exactly the four
actual click/paging interaction cases still fail because no valid row selection
reaches the parent. The next-page request itself succeeds. Both templates then
bind selectedChange and wrap its array for the unchanged object-shaped handler.
All test-source hashes remain identical; there are no mock table events, relaxed
HTTP request expectations or removed assertions.

The fully corrected v25 integration passes all 31 cases with normal CLI exit.
Exact source hashes match the corrected old-library and both incompatible-v25
controls. Frozen manifests remain unchanged by installation, and all other
installed package versions stay unchanged. No full native package or Storybook
build is inferred from these focused results.

An initial archive-source substring probe selected the first fesm member rather
than the root implementation. Its compact admission receipt was overwritten
before preservation; an explicitly reconstructed initial receipt and correction
note distinguish that mistake from original evidence. The unchanged published
archive, exact root-source lines and public compiler declarations establish the
actual selected-model API.
