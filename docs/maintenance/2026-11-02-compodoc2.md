# Compodoc 2 with preserved Storybook primitive controls

This corrected replacement adopts exact Compodoc 2.0.0 for the current Angular 22,
TypeScript 6 and Node 26 project. It supersedes #235's older 1.2.1 target and
implements #293's major target without merging either historical lock refresh.
Only this direct selection changes; 73 other direct installed versions and every
retained lock selector resolution stay fixed. Selectors decrease from 2,022 to
1,670. The 56 new package versions have no install hooks. Official artifact SRI
and all 344 installed Compodoc members match. Ordinary frozen installation passes.
[Release](https://github.com/compodoc/compodoc/releases/tag/v2.0.0).

A real consumer comparison found that Compodoc 2 emits unknown for some
unannotated initialized properties. Storybook no longer infers primitive controls
from their defaults. The documentation-only adapter restores boolean, string and
finite-number types from literal defaults in a cloned metadata object. It does
not evaluate source, replace known types, infer objects or execute expressions.
Production application source and database/Wails contracts are unchanged. Two
new regressions fail before this correction; all ten Node bridge, framework and
documentation checks pass afterward. No application test or threshold is relaxed.

All documented entity inventories and their source code remain identical,
including 134 components and four directives. Public input/output names, types
and defaults are unchanged. There are 532 empty-description formatting changes.
One newly reported OnPush default agrees with the Angular 22 compiler's default
for an unannotated component; it is not an explicit source annotation. The actual
Storybook reader runs in a fresh isolated Chrome profile: all 252 checked entities
map without losing member names, all 328 public input/output descriptors remain
equivalent apart from empty-description formatting, and all 254 boolean/number
controls retain types, defaults and requiredness. This includes 27 affected
booleans whose formerly blank table labels now explicitly say boolean.

All member metadata is not byte-equivalent. Internal unknown/object/signature
renderings and improved inline types are retained in the raw comparison. The
initial whole-metadata equality diagnostic fails and stays retained. The first
browser renders its comparison but fails native teardown; its script exits 1,
and the helper did not capture the numeric child status. Later isolated probes
using the existing Karma disable-gpu mode exit 0. The corrected strict-descriptor
diagnostic still exits 1 because 27 blank table labels now say boolean. Its full
result is independently checked: control types, values and requiredness are
unchanged, and those exact label changes are recorded rather than hidden. No
application test assertion was changed to accommodate a diagnostic failure.

The ordinary browser suite passes 423 tests with one existing skip and exits 0.
Production and both initial/corrected Storybook builds pass. All 22,287 produced
application files match the current validated native frontend, so no new native
smoke run is claimed. Original documentation was absent and remains absent; all
new generated metadata and builds are retained privately. Raw regenerated JSON
bytes differ only because miscellaneous.typealiases (55 objects) and variables
(245 objects) are reordered. Exact multiset comparison preserves all contents
and multiplicities, and every other section is identical. The initial byte-only
comparison helper exits 1 and its receipt is retained; this is not a failed build.
The complete original installed tree, native metadata and current historical tips remain recoverable.
Five vis-network peer warnings are retained; this project consumes Compodoc JSON
and its existing consumer passes without forcing peers or adding direct packages.
The TypeScript-only documentation helper also produces a Node module-inference
warning during its native Node tests; repository module mode is unchanged.
