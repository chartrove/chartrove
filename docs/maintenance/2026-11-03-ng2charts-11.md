# Angular 22 chart directive migration

The corrected replacement for #307 advances ng2-charts 4.1.1 to 11.0.0.
The published peer ranges accept the existing Angular/CDK 22, Chart.js 4.6.1
and RxJS 7.8.2 versions. The new dependency es-toolkit 1.53.1 has no runtime
dependencies and retains its MIT license. The former sole consumer of lodash-es
is replaced, so that orphan lock block is removed. The separate lodash package
and every other dependency lock block remain unchanged. Frozen installation
and the complete installed-package inventory confirm exactly those changes.

Version 11 exports a standalone BaseChartDirective and provideCharts rather
than NgChartsModule. ChartroveChartsModule imports/exports that directive and
provides the official default registerables. Fourteen existing import sites,
including standalone widgets, clinical cards, application/shared modules and
Storybook metadata, retain the same module-consumption shape. No manual chart
registration is added to tests; isolated component consumers exercise the real
provider setup. Query logic, chart options, raw observations, backend contracts,
database models, encryption and native bridge source are unchanged.

The identical focused suite passes all 11 cases on both versions: four populated dashboard
chart consumers and seven clinical-chart cases, including real canvas rendering
with zero measurements, inclusive reference bounds, raw-record preservation and
registry disposal. The new clinical assertion initially failed TypeScript
compilation because BarElement exposes geometry through getProps, rather than a
declared width field. The corrected test retains the positive-width assertion;
both initial source and failed log are preserved. No assertion is weakened.

Application noEmit type checking and the changed Storybook story with its
transitive imports pass. The broad raw Storybook type-check invocation first
rejected source files outside its default .storybook rootDir; explicit frontend
rootDir then found absent generated documentation.json. Both failed logs are
retained. The focused story check retains the original compiler options, includes
its real imports and supplies no documentation stub. This is not a full Storybook
build. [Compact validation](ng2charts-validation.json).

The initial focused compile used Angular's default local persistent cache.
Subsequent focused runs set CI=true to disable that local-only cache and use
private temporary coverage/build output. Existing caches are untouched. Full
local frontend/Storybook/native workflows remain subject to the unchanged
50 GiB reserve. No new packaged native UI acceptance is claimed; the last local
qualified package predates these dependency updates. Protected Backend,
Frontend and Desktop checks remain mandatory before integration.
