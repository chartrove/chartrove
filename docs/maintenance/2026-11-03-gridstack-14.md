# GridStack dashboard compatibility

The replacement targets #302's GridStack 14.0.0 and supersedes #243's overlapping
8.4.0 proposal. Only the direct gridstack selector and its leaf lock block change;
all other dependency selectors/lock bytes remain unchanged. The published archive
passes registry SHA-1/SHA-512 checks and every published file matches installation
after consumer validation. A new dist/angular/package.json is packaged content,
not another dependency update; the first version-vector admission mistook it for
one and stopped. The corrected vector proves all external versions unchanged.

The attributed Chartrove Angular adapter remains in place. The upstream v13
packaged-wrapper field renames do not apply to this custom adapter: its existing
type/widgetConfig serialization is preserved and tested. V14 removes the float
TypeScript option, so dashboard float:false becomes mode:top. Explicit <=768px
one-column breakpoints preserve v8's formerly implicit responsive behavior.
No stored dashboard data, provider code, FHIR payloads, database or Wails contract
is migrated. This does not implement the application's unfinished dashboard
export/persistence UI; it validates the library/adapter round-trip API.

Three identical final real-browser cases pass on old 8.1.1 and corrected 14.0.0:
registered widget/configuration round-trip (including zero/false), rendered
1200px-grid card geometry after updates (500x120px at x=400px), change/removal
callbacks, real public drag/resize state, and narrow-to-wide column restoration.
