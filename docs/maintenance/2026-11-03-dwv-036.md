## Corrected application contracts

The legacy image.decoderScripts and utils exports are removed in v0.36;
unadapted application typing fails on both before runtime assertions. The
corrected component uses typed AppOptions, ViewConfig and ToolConfig, string
data IDs, the plural setDataViewConfigs method and the public simple-metadata
conversion. BinaryModel data remains the original base64 value. No stored record,
database/SQLCipher contract, provider SDK, Wails binding or migration changes.

Workers now load relative to document.baseURI under assets/workers. Build, test
and Storybook asset mappings copy the actual dist/assets tree there. The initial
candidate RLE control failed under the obsolete decoder layout; serving the
unchanged published worker at its required path corrects it. No library payload
or worker protocol is patched. Initial old/new uncompressed and old RLE results
remain alongside that failure.

Initialization waits for its view container, and each component owns a unique
layerGroup ID. The ID avoids an embedded -layer- token that DWV reserves for
event routing. Teardown removes this component's resize and library listeners,
aborts its loads and resets its own viewer. Old tests reproduce a missing resize
removal; simultaneous-canvas tests pass on old too, so no cross-record mixing
defect is claimed. Unavailable controls are disabled. Malformed encoded input
gets a generic scoped status without changing its data or opening an alert.
Synchronous initialization-error status is published after Angular's initial
view check, with a destruction guard; asynchronous library errors remain handled.
